# Conference badge provenance

Checked 2026-10-10 against the ICORE2026 portal. ACCV and MMM are B; ICMV is C. ECCV main conference is A*, but the AI City paper is a workshop paper, so it uses a neutral Workshop badge and is not assigned A*.

MAPR and SOICT use an indexing color, not a CORE rank. MAPR indexing is reported by UIT; SOICT 2025 indexing is announced on its official conference page. This does not assert independent verification of each paper in a Scopus subscription database. Sources are stored in `_data/venue_rankings.yml`.

Travel destinations and personal attendance come from the user's instructions and existing portfolio notes. ACCV and SIGGRAPH Asia 2026 are marked Upcoming. No stock travel photos or additional personal trips are inferred. The ECCV photo is the existing portrait from that trip.
