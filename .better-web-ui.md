## Design Context

### Users
This is Thanh-Nhan Vo's academic portfolio. Readers review research, publications, experience, and contact information. The existing opportunity callout addresses prospective research collaborators and supervisors.

### Brand Personality
Academic, calm, personal. The owner prefers a light academic style and requested a restrained autumn effect, with only a few falling yellow leaves.

### Aesthetic Direction
Preserve the existing typography, blue links, white content cards, and readable layout. The owner wants muted ochre leaves scattered randomly across the full viewport, not grouped into columns at the edges. Keep leaves small and translucent as they cross content, with pointer events disabled.

### Implementation Defaults
Preserve the existing Jekyll, Bootstrap 4, vanilla CSS, and JavaScript stack. Use CSS transforms and opacity for decorative motion, with no animation dependencies or continuous JavaScript rendering loop.

### Design Principles
1. Keep research content and navigation visually primary.
2. Use ten leaves on desktop and five on mobile, with random positions, sizes, tilt, and drift. Pick a fresh path each falling cycle rather than repeating fixed columns.
3. Honor reduced motion and provide a visible control to turn decoration off.
4. Preserve clear text, pointer interactions, and the existing responsive layout.
5. The current autumn experiment is local only. Do not commit or push it without the owner's request.
